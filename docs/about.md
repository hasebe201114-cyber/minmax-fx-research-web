# プロジェクト概要

## minmax チームについて

minmax チームは、クオンツ領域の検証ラボ群を運営しています。

| プロジェクト | 役割 |
|---|---|
| **minmax-trading-pilot** | FX 自動売買システム構築の親プロジェクト |
| **minmax-fx-day-trading-lab** | マルチタイムフレーム・FX 戦略の検証ラボ (本サイトの出典) |
| **minmax-fx-research-web** (本サイト) | 上記ラボの研究成果の一般公開 |
| lp-strategy-lab, crypto-strategy-lab, tradfi-strategy-lab | 関連戦略の検証ラボ (別チーム) |

## 検証アプローチ

`minmax-fx-day-trading-lab` では以下の体制で検証を進めています:

### マルチエージェント体制 (6 体)

- **S 戦略 (chief-strategist)**: 大局観, 戦略優先順位
- **A 設計 (strategy-architect)**: 検証仕様 (spec) 確定
- **B 実装 (quant-researcher)**: spec に忠実な実装
- **C 品質 (adversarial-reviewer)**: 良好結果への懐疑的検証
- **D デプロイ (integration-deploy)**: 採用後の実行基盤接続
- **E 進行 (archivist-pm)**: 引き継ぎ, 採用台帳

### 評価基準 (K1m 〜 K7m)

| 指標 | 内容 | 合格ライン |
|---|---|---|
| **K1m** | 月次 Sharpe / PF / 期待値 | Sharpe ≥ 0.4, PF ≥ 1.2, 期待値 > 0 |
| **K2m** | 月間 / 年間最大DD | 月 ≤ 10%, 年 ≤ 20% |
| **K3m** | 最大連続損失 | ≤ 5 |
| **K4m** | ペイオフレシオ | ≥ 1.5 |
| **K5m** | 1 トレード期待値 | > スプレッド往復 × 3 |
| **K6m** | BT ↔ FT 乖離率 | ≤ 30% |
| **K7m** | 両建て証拠金消費率 | ≤ 30% |

すべての指標を満たす戦略のみが本番採用候補となります。

## 対象通貨ペア (5 通貨)

| 通貨 | スプレッド (pips) | 備考 |
|---|---|---|
| USD/JPY | 0.3 | 基軸通貨, 流動性最大 |
| EUR/JPY | 0.5 | 欧州勢 |
| GBP/JPY | 0.7 | ボラティリティ高 |
| AUD/JPY | 0.6 | キャリートレード人気 |
| EUR/USD | 0.3 | ドル以外の基軸 |
