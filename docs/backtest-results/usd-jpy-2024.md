## OBS000003 採用判定

### 理由

1. **期待値 +12.0 JPY は K5m 基準 (スプレッド往復 × 3) を下回る**
   - USD/JPY スプレッド往復 = 0.3 × 2 = 0.6 pips
   - K5m 基準 = 0.6 × 3 = 1.8 pips ≒ 180 JPY (1 lot 想定)
   - 期待値 12.0 JPY ≒ 0.12 pips → K5m 基準 1.8 pips の **6.7%** のみ
2. **ペイオフレシオ 1.45 < 1.5** (K4m 違反)
3. **最大連続負 5** (K3m ぎりぎり)
4. EUR/JPY 等他通貨で代替可能
