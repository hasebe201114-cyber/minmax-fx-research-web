## 評価指標の解釈

### Sharpe (月次)
- 0.0 〜 0.5: 限定的エッジ
- 0.5 〜 1.0: 良好なエッジ
- 1.0+: 強いエッジ (要過学習検証)

### Profit Factor (PF)
- < 1.0: 損失
- 1.0 〜 1.2: 限定的
- 1.2 〜 1.5: 良好
- 1.5+: 強い

### 最大DD (月次 %)
- ≤ 5%: 非常に安定
- 5% 〜 10%: 良好 (K2m 合格)
- 10% 〜 20%: 警戒
- 20%+: 危険

### 連続負
- ≤ 3: 良好
- 3 〜 5: 合格圏 (K3m ≤ 5)
- 5+: 改善必要
