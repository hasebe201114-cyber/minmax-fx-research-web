## OBS000003 (USD/JPY REJECT) の理由

1. **期待値 < スプレッド往復 × 3** (K5m 違反)
2. **最大連続負 = 5** (K3m ぎりぎり, 余裕度不足)
3. **EUR/JPY 等他通貨で代替可能**

## OBS000004 (AUD/JPY 保留) の理由

1. 期待値 +107.9 JPY は健全だが、**スワップ未考慮** で評価
2. スワップ込み再評価で黒字維持確認 (+5,828 JPY, +3.0% 改善)
3. ただし、Train 2020-2022 / Val 2023-2024.6 / Test 2024.7-2025.12 の **3 期間分離検証が未完了** (現在実行中)
4. 過学習の有無が確認できるまで「採用」は保留
