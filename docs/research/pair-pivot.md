## 通貨別考察

### USD/JPY: REJECT
- 4 通貨中で最大ドロー (15 連敗) と最悪 PnL (-19,019 JPY)
- A1+A2 複合でも黒字化未達、USD/JPY 2024 のボックス相場にエッジが機能せず
- 詳細は [USD/JPY 2024](../backtest-results/usd-jpy-2024.md) を参照

### EUR/JPY: REJECT
- 70 トレードとサンプルは多いが PF 0.827 で赤字
- シャープ -0.345、K1m 違反
- USD/JPY よりは「惜しい」が黒字化未達

### GBP/JPY: CONDITIONAL
- 57 トレードで PF 1.119、+1,701 JPY の薄黒字
- シャープ +0.224 と K1m 合格 (≥ 0.4) には届かず
- ペイオフレシオ 1.538 と K4m ギリギリ、連続負 5 で K3m 余裕度不足
- 「採用候補の次点」だが根拠不足

### AUD/JPY: 保留 (PROVISIONAL ACCEPT 待ち)
- 4 通貨中で唯一 K1m〜K5m すべてクリア (シャープ 1.80 ≥ 0.4, PF 1.99 ≥ 1.2, 期待値 +108 > 0, 連続負 3 ≤ 5, ペイオフレシオ 1.48 → スワップ込みで 1.48 だが 1.5 へ届かず)
- **スワップ込み再評価** (`data/curated/ds-7.json`) で黒字維持確認 (PF 1.99, シャープ 1.80, PnL +5,828, 連続負 3)
- ただし **Train 2020-2022 / Val 2023-2024.6 / Test 2024.7-2025.12 の 3 期間分離検証が未完了** (差し戻し 3)
- 過学習の有無が確認できるまで「採用」は保留
- 詳細は [AUD/JPY 2024](../backtest-results/aud-jpy-2024.md) を参照

### EUR/USD: REJECT (要再設計)
- 49 連敗すべて負け (n_wins = 0)、PF 0.000
- **pips スケール問題**: USD/JPY 比 1/100 のため SL 1.5 ATR が小さすぎて全敗
- pips ベース固定 SL (5-8 pips) または ATR 乗数大幅増 (3.0-4.0) のプリセット再設計が必要
- 詳細は [EUR/USD 2024](../backtest-results/eur-usd-2024.md) を参照

## 結論

- **AUD/JPY が現状唯一の有望通貨** (スワップ込みで黒字、過学習検証待ち)
- GBP/JPY は CONDITIONAL で追加検証 (決済微調整, ADX 閾値調整) の余地あり
- USD/JPY / EUR/JPY / EUR/USD は A1_A2_combined プリセットでは黒字化未達
- EUR/USD は pips スケール問題のため**戦略の再設計**が必要

- 全 7 つの差し戻し対応完了後、C 判定レビュー再実施 (差し戻し 7)
