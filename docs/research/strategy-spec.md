# 戦略仕様 (SYS-FX007 v2.1)

> 詳細仕様はラボ PJ の `research/EXP-FX000001/00-spec.md` を参照してください。
> ここでは一般公開向けのサマリのみ記載します。

## システム概要

SYS-FX007 は **レンジブレイク・プルバック** 戦略の検証実装で、以下の特徴を持ちます:

- **マルチタイムフレーム**: 長期 (D1/W1) で方向を判定、中期 (H4/H1) でレンジを決定、短期 (M15/M5) でエントリー
- **MT-3 フォールバック**: 中期足のセンチメント指標は当面恒久フォールバック (4 条件 AND 評価)
- **v2.1 で確定**: MT-1 + MT-2 必須、MT-3 は将来 DS-8 取得後に再有効化予定

## 評価基準 (K1m 〜 K7m)

すべての指標を満たす必要があります。

| 指標 | 計算 | 合格ライン |
|---|---|---|
| K1m_sharpe | 月次 Sharpe | ≥ 0.4 |
| K1m_pf | 月次 Profit Factor | ≥ 1.2 |
| K1m_expectancy | 1 トレード期待値 (JPY) | > 0 |
| K2m_dd_monthly | 月間最大DD | ≤ 10% |
| K2m_dd_yearly | 年間最大DD | ≤ 20% |
| K3m_consec | 最大連続損失 | ≤ 5 |
| K4m_payoff | ペイオフレシオ | ≥ 1.5 |
| K5m_unit_ev | スプレッド往復 × 3 | 期待値が超える |
| K6m_bt_ft | BT ↔ FT 乖離率 | ≤ 30% |
| K7m_margin | 両建て証拠金消費率 | ≤ 30% |
