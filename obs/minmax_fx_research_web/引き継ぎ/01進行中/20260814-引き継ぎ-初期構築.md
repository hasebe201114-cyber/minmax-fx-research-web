## 3. 並走ルール (ラボ PJ との非干渉)

**最重要**: 本PJは `minmax-fx-day-trading-lab` の研究プロセス (バックテスト実行中等) に**一切干渉しない**こと。

### 触って良いもの
- 本PJディレクトリ配下 (`minmax-fx-research-web/`)
- ラボ PJ の **読み取り専用参照** (Markdown, JSON の中身を読むだけ)
- 公開前のデータ抽出・整形 (**ラボ PJ から本PJへコピー** が基本)

- ラボ PJ の `research/EXP-FX000001/10-result/` の変更
- ラボ PJ で実行中の Python プロセス
- ラボ PJ の `scripts/run_train_val_test.py` などの編集

## 6. 既知の罠 (次セッションが踏む前に)

1. **MkDocs Material 日本語フォント**: `Noto Sans JP` を指定済み。フォールバックで システムフォントに自動切替
2. **GitHub Pages の deploy**: 初回は Settings → Pages → Source: GitHub Actions を選択する必要あり
3. **ラボ PJ の JSON パス**: 必ず **コピー** (移動禁止)、本PJに取り込み後もラボ PJ の原本は触らない
4. **画像ファイルサイズ**: PNG 1 枚 1 MB 以下を目安 (Web ページ表示速度のため)
5. **機密情報混入防止**: API キー / `.env.local` / 口座残高 / 個人損益 を取り込まない
6. **更新タイミング**: ラボ PJ の差し戻し 3-7 完了後にまとめて同期 (部分同期だと中途半端)
