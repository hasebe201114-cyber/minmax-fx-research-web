    現状¶

    • スワップ込みで K1m〜K5m 概ねクリア (K4m のみ 1.48 < 1.5 でギリギリ)
    • AUD/JPY はキャリートレード人気通貨でスワップ益が戦略を後押し
    • スワップ益は 1 トレード平均 +3.2 JPY (控えめ)、大半は値動き益

    保留理由 (差し戻し 3-7 未完了)¶

    1. train/val/test 分離検証が未完了 (差し戻し 3, 4-6 時間)
    2. Train 2020-2022 / Val 2023-2024.6 / Test 2024.7-2025.12 の 3 期間で過学習の有無を確認
    3. permutation test + 多重比較補正が未実装 (差し戻し 4, 2-3 時間)
    4. 5 通貨 × 複数プリセット (5×5=25 候補) で Bonferroni 補正 (α = 0.002)
    5. 両建てロジック統合 + K7m 実測が未完了 (差し戻し 5, 4-6 時間)
    6. ATR ベース SL の通貨間スケール依存検証が未完了 (差し戻し 6, 2 時間)

    既知の制約¶

    • data/curated/ds-7.json のスワップ値は概算 (GMO 公式スワップデータで再計算必須)
    • EUR_USD のスワップは JPY 換算が複雑なため 0.0 固定 (本評価には無関係)
